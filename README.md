# AgentWeather

AI-powered 24-hour weather and air-quality forecasting platform.

## Project Overview

AgentWeather forecasts weather and air-quality conditions for Abbottabad, Pakistan using machine learning and AI agents.

## Technology Stack

- Python
- Scikit-learn
- TensorFlow
- SARIMAX
- Hopsworks
- LangGraph
- Groq
- Streamlit
- GitHub Actions
